# AI_tools

A collection of Python utilities to improve productivity and workflow in AI development projects.

## Current Tools

- **merge_py**: Merge multiple Python files into a single file with relative paths. Ideal for sharing code with AI models.

## Planned Modules

- **data_processing**: Utilities for cleaning, transforming, and analyzing data
- **visualization**: Tools to create plots and dashboards
- **scripts**: Miscellaneous scripts to automate tasks

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/AI_tools.git
````

2. Navigate to the tool folder you want to use:

```bash
cd AI_tools/merge_py
```

3. Install dependencies:

```bash
pip install -r ../../requirements.txt
```

4. Run the tool (example for merge_py):

```bash
python merge_tool_cli.py
```

## Contributing

Feel free to contribute new AI-related utilities. Keep each tool in a separate folder with its own README explaining its purpose.
